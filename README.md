# Meu Primeiro Site HTML

Este projeto foi desenvolvido com o objetivo de praticar os conceitos básicos de HTML.

Foram utilizados títulos, parágrafos, listas, links e diferentes formas de formatação de texto para apresentar conceitos sobre Computação, Internet e HTML.

## Tags utilizadas

- h1 até h3
- p
- strong
- mark
- small
- i
- u
- ol
- ul
- li
- a
- hr
- sub
- sup
- blockquote
- font
- del
- abbr

## Ferramentas utilizadas

- Visual Studio Code
- Git
- GitHub
- HTML5

## Aprendizados

Neste projeto aprendi a criar a estrutura básica de uma página HTML, utilizar diferentes tags de formatação e publicar um projeto utilizando GitHub.
