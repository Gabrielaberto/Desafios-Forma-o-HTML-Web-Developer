O Surgimento da Internet

A Internet surgiu durante a década de 1960 através de um projeto chamado ARPANET, criado pelo governo dos Estados Unidos.

O objetivo inicial era permitir a comunicação entre centros de pesquisa e universidades mesmo em situações de emergência.

Com o passar dos anos, novas tecnologias foram sendo criadas e a rede passou a conectar computadores em todo o mundo.

A Internet transformou a forma como estudamos, trabalhamos e nos comunicamos.

O que é HTML?

HTML significa HyperText Markup Language, que em português significa Linguagem de Marcação de Hipertexto.

O HTML é utilizado para organizar e estruturar o conteúdo de uma página web.

Ele informa ao navegador onde existem títulos, parágrafos, imagens, listas e links.

O HTML é considerado uma linguagem de marcação.

Observação: HTML não é uma linguagem de programação.

O que são Tags?

Tags são comandos utilizados para estruturar uma página HTML.

Cada tag possui uma função específica.

  • A tag h1 cria títulos.
  • A tag p cria parágrafos.
  • A tag a cria links.
  • A tag ul cria listas.

Também podemos formatar palavras utilizando itálico, sublinhado ou negrito.

Diferença entre HTML e Linguagens de Programação

Muitas pessoas acreditam que HTML é uma linguagem de programação, mas isso não é correto.

O HTML apenas organiza o conteúdo da página.

Linguagens como Python, Java e JavaScript são capazes de realizar cálculos, tomar decisões e executar instruções.

Veja alguns exemplos:

  • HTML organiza a página.
  • CSS personaliza a aparência da página.
  • JavaScript adiciona interatividade.
